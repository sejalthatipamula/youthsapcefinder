# YouthSpaceFinder

Helps students book community spaces (libraries, churches, parks, community centers) for student-led sessions and initiatives.

## Roles

| Role | Who | Workflow | Data models |
| --- | --- | --- | --- |
| Student | Leads an initiative and books spaces | [student-workflow.md](student-workflow.md) | [student-data-models.md](student-data-models.md) |
| Reviewer | Trusted adult sponsor who vets initiatives and session requests | [reviewer-workflow.md](reviewer-workflow.md) | [reviewer-data-models.md](reviewer-data-models.md) |
| Host | Venue that lists spaces and approves bookings | [host-workflow.md](host-workflow.md) | [host-data-models.md](host-data-models.md) |
| Admin | Verifies hosts and reviewers, handles reports and disputes | [admin-workflow.md](admin-workflow.md) | [admin-data-models.md](admin-data-models.md) |

Overview of all entities and statuses: [data-models.md](data-models.md)

## Booking flow

Student requests → Reviewer approves → Host approves → Confirmed → Completed
